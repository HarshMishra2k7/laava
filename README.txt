## Website chalana
`index.html` par double-click karo. Chrome me website open ho jayegi.

## GitHub par public karke Lavanya ko link bhejna
1. GitHub.com par login karo.
2. **New repository** banao, example: `lavanya-birthday`.
3. Repository ko **Public** select karo.
4. Is ZIP ko extract karo.
5. `index.html`, `style.css`, `script.js` aur poora `images` folder GitHub repository me upload karo.
6. GitHub repository me **Settings → Pages** kholo.
7. **Build and deployment → Deploy from a branch** select karo.
8. Branch: `main`, folder: `/ (root)` select karke **Save** karo.
9. Thodi der baad GitHub ek public URL dega, usually:
   `https://YOUR-USERNAME.github.io/lavanya-birthday/`
10. Isi link ko WhatsApp/Instagram par Lavanya ko send kar dena. ❤️

IMPORTANT: `index.html`, `style.css`, `script.js` aur `images` folder same level par rehne chahiye.
